## Featured Project

### 🌿 LeafNest — AI Ecosystem & Biodiversity Scanner (Capstone, 2026)
Mobile app built with **React Native, Node.js, and Firebase** that identifies plant and animal species through real-time image recognition.

- Integrated **Google Cloud Vision API**, **iNaturalist API**, and **GBIF API** for accurate species ID
- Features: user auth, guest mode, scan history, favorites, multilingual support, text-to-speech, push notifications, statistics dashboard, achievement system, PDF export via email, trending species, and a social-feed for sharing discoveries
- Designed the UI in **Figma**, optimized for Android using **Expo**
- Built with a 5-member team using **Scrum Agile** methodology
